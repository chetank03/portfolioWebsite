# Chetan Kodeboyina Portfolio

Personal portfolio website for Chetan Kodeboyina, built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

The site presents software engineering experience, education, projects, skills, and contact links in a single-page portfolio format. Portfolio content is stored locally in `data/portfolioData.ts`, so the site can be edited without a CMS.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- React Social Icons

## Run Locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production Build

Create an optimized build:

```bash
npm run build
```

Run the production server:

```bash
npm run start
```

## Editing Content

Most portfolio content is defined in:

```text
data/portfolioData.ts
```

Update that file to change experience, education, projects, skills, social links, or contact information.
